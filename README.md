# Retrieval-Augmented Generation (RAG) for Domain-Specific Question Answering

## Project Overview

This project implements a Retrieval-Augmented Generation (RAG) system that answers questions from domain-specific documents using a pretrained Large Language Model (LLM).

The system retrieves relevant information from uploaded PDF or TXT documents using semantic search and generates context-aware answers using Google's FLAN-T5 model.

It also compares the responses generated by the LLM with and without document retrieval to understand the benefits of the RAG approach.

## Objectives

- Implement a Retrieval-Augmented Generation pipeline.
- Extract and preprocess text from domain-specific documents.
- Divide documents into smaller text chunks.
- Generate embeddings using Sentence Transformers.
- Store and retrieve document embeddings using FAISS.
- Generate answers using a pretrained LLM.
- Compare responses generated with and without RAG.

## System Workflow

1. Upload domain-specific PDF or TXT documents.
2. Extract text from the uploaded documents.
3. Split the extracted text into smaller chunks.
4. Generate vector embeddings using Sentence Transformers.
5. Store embeddings in the FAISS vector database.
6. Accept a user question.
7. Retrieve the most relevant document chunks.
8. Generate an answer using the retrieved context and FLAN-T5.
9. Generate another answer using FLAN-T5 without retrieval.
10. Compare both responses.

## Model Details

**Embedding Model:** sentence-transformers/all-MiniLM-L6-v2

**Language Model:** google/flan-t5-base

**Vector Database:** FAISS (Facebook AI Similarity Search)

## Results and Evaluation

The project evaluates:

- Document extraction and preprocessing.
- Text chunking and embedding generation.
- Relevant document retrieval using FAISS.
- Answer generation without retrieval.
- Answer generation with retrieval.
- Comparison of answer relevance and contextual accuracy.

The results demonstrate how retrieval can provide additional document-specific context to a pretrained LLM.

## Conclusion

This project demonstrates the integration of information retrieval and language generation through a RAG pipeline. By retrieving relevant document information before generating responses, the system aims to improve domain-specific question answering and reduce unsupported responses compared with a standalone LLM.
